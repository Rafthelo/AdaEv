# AdaEv

Plataforma modular para gestión de eventos, ventas, inventario, caja, auditoría y operaciones organizacionales.

## Stack

- **Backend:** Node.js + Express + MySQL 8 + JWT + Socket.IO
- **Frontend:** React + Vite + TailwindCSS + Axios + React Router
- **Base de datos:** MySQL 8 (SQL puro)
